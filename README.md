# Workeera Tracker | Simple Time Tracking for Freelancers

**Live website:** [https://tracker.workeera.com/](https://tracker.workeera.com/)

Workeera Tracker is a simple, single-page time tracking tool for freelancers. It lets you track work without creating an account or signing in.

Track time across multiple projects or tasks, configure a separate time zone and currency for each timer, and export timesheets when you need them. Your data stays in your browser until you choose to sync it.

## Features

- **No account required:** Start tracking time without signing up or logging in.
- **Single-page workflow:** Use the timer and timesheet tools from one focused interface.
- **Multiple concurrent timers:** Run up to five timers at the same time.
- **Per-timer settings:** Configure an individual time zone and currency for each timer.
- **Timesheet exports:** Export tracked time as CSV or PDF.
- **Browser-based data storage:** Your data stays in your browser until you choose to sync.
- **Freelancer-focused:** Track time across clients, projects, and tasks.

## How to Use

1. Open [tracker.workeera.com](https://tracker.workeera.com/).
2. Start a timer for the task or project you are working on.
3. Add more timers as needed — up to five can run concurrently.
4. Set the appropriate time zone and currency for each timer.
5. Review your tracked time and export a CSV or PDF timesheet.

No account is required to start using the tracker.

## Privacy & Data

Workeera Tracker is designed to keep your tracking data in the browser. The live product states that data stays on your device until you choose to sync it.

For details about optional sync functionality and other website data, refer to the information provided on the live website.
